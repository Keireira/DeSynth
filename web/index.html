Help

Open and process
Open a source image, set parameters and click Process. Generation settings apply to the next run. Restoration settings can be adjusted after generation.
Compare
Choose a mode in the bottom toolbar. Drag the divider in Slider mode. Side by side shows both images. Original and Result show one image at a time.
Zoom and pan
Scroll to zoom and drag to pan. Fit to view resets the view. Use the arrow keys while the divider is focused to move it.
Difference map
Diff shows absolute pixel differences. Black means identical. Gain amplifies changes. RGBA includes color and transparency; Alpha shows transparency changes alone.
Settings
Open Settings to choose the GGUF model, Lightning adapter, device, offload mode and precision. Automatic selects the available default adapter. At Denoise 0.25, Steps 32 gives 8 actual sampling steps; changing the adapter does not change your Steps setting. Auto selects a compatible device and precision. Sequential offload uses the least VRAM and is slowest; Model offload uses more VRAM; Disabled keeps the model on GPU. CPU does not use offload.
Parameters
Denoise controls the strength of changes. Steps sets the full diffusion schedule; img2img runs a fraction of it according to Denoise. Passes repeats generation. Use a fixed seed for repeatable comparisons. Sigma controls detail restoration scale; Edge follows contours. Sharpen adds final sharpening.
Export
Export PNG saves the selected image or difference map. PNG supports transparency.
